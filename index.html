Respaldo y datos

Los registros se guardan en una base de datos central compartida. Todo el personal autorizado ve los mismos registros, búsquedas y dashboards desde cualquier equipo. Puede importar aquí respaldos JSON de la versión anterior para subirlos a la base central.
Estado de los datos

Consejo: exporte respaldos con regularidad y guárdelos en una ubicación institucional autorizada. Cierre sesión al terminar si usa un equipo compartido.
